🛰️ Cybersecurity Risk Assessment

A hands-on cybersecurity assessment focused on identifying, analyzing, and reducing security risks across identities, endpoints, networks, applications, and data.

🎯 Objective

Identify major security risks, determine their severity, map them to security controls, and create a prioritized remediation strategy.

⚠️ Key Risks Identified

  • Phishing and credential theft — Critical
  • Ransomware — Critical
  • Excessive privileged access — Critical
  • Unpatched systems — High
  • Insufficient security monitoring — High
  • Data leakage — High

🛡️ Security Controls

  • MFA and Conditional Access
  • Least Privilege and PIM
  • Endpoint Detection and Response
  • Patch and Vulnerability Management
  • Data Loss Prevention and Encryption
  • Centralized Logging and SIEM
  • Secure and Tested Backups

☁️ Hands-On Lab

The assessment can be demonstrated using Azure security services, including Microsoft Entra ID, Defender for Cloud, Log Analytics, and Microsoft Sentinel.

📊 Risk Methodology

Risk Score = Likelihood × Impact

Risks were prioritized and assigned remediation actions based on their potential effect on business operations.

🔧 Remediation

Critical risks were prioritized first, followed by improvements to patch management, monitoring, endpoint security, data protection, and access control.

✅ Outcome

The project produced a prioritized risk register, security control mapping, remediation roadmap, and evidence-based assessment of the organization's security posture.
